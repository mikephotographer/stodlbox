Damit die App am Home-Bildschirm direkt im Admin-Bereich startet, leg sie von dieser Seite aus an:

  1. Unten (Safari) bzw. oben (Chrome) auf Teilen tippen.
  2. Zum Home-Bildschirm wählen. Als Name sollte „Stodl Admin“ stehen.
  3. Die neue App öffnen und mit dem Code aus der Mail anmelden.
